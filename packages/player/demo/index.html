AutoCell-Player

Zelluläre Automaten aus AutoCell in jede Webseite einbinden – mit einer Zeile Skript und einem HTML-Element.

Einbinden

Das Skript einmal pro Seite laden:

<script type="module" src="https://delbonum.github.io/autocell/player/autocell-player.js"></script>

Dann ein in AutoCell gespeichertes Projekt abspielen. Die Datei liegt neben der Webseite:

<autocell-player src="mein-projekt.acp" controls autoplay></autocell-player>

Am einfachsten geht es in AutoCell über Datei › Im Web veröffentlichen: Dort lässt sich das Projekt auch direkt in den Code-Schnipsel einbetten, ganz ohne separate Datei.

Eingebettetes Projekt

Ein Gleiter auf einem 16 × 16-Torus. Er wandert 64 Generationen lang, dann beginnt die Wiedergabe dank loop von vorn. Das Projekt steht als JSON direkt im Element: 

<autocell-player controls loop>
  <script type="application/json">
    { "format": "autocell-project", … }
  </script>
</autocell-player>

Vorlagen

Mit template startet eine zufällig belegte Vorlage: gol, sir, traffic, fire oder brain.

Attribute

AttributBedeutung
srcAdresse einer .acp-Datei (oder ihrer JSON-Variante). Liegt sie auf einem anderen Server, muss dieser CORS erlauben.
templateVorlage statt Projektdatei, dazu optional cols, rows und seed.
controlsSteuerleiste mit Start/Pause, Einzelschritt, Zurücksetzen und Generation.
legendZustände mit Farbe und aktueller Anzahl.
autoplayStartet automatisch, sobald der Player sichtbar ist. Entfällt, wenn im Betriebssystem „Bewegung reduzieren“ eingestellt ist.
loopBeginnt von vorn, wenn eine Stoppbedingung des Projekts erreicht ist.
interactiveZellen per Klick oder Ziehen auf den nächsten Zustand setzen.
speedTempo in Generationen pro Sekunde (sonst das im Projekt gespeicherte).

Gestaltung und Skripte

Der Player füllt die verfügbare Breite. Über CSS lassen sich die Höhe begrenzen und die Leisten anpassen: 

autocell-player {
  --autocell-max-height: 400px;
  --autocell-bar-bg: #222;
  --autocell-bar-fg: #fff;
}
autocell-player::part(controls) { border-top: 1px solid #444; }

Per JavaScript stehen play(), pause(), toggle(), step(), reset() und load(…) bereit, dazu die Eigenschaften playing, generation und projectName. Der Player meldet die Ereignisse load, error, play, pause und end.
